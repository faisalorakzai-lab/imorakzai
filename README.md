# I’M ORAKZAI

A 200-page research-based book documenting Orakzai and Pashtun history, culture, identity, society, migration, Pakistan, technology, AI, blockchain, digital sovereignty, entrepreneurship, and the future.

## Project Structure
- `/book`: Contains the book content and assets.
  - `/pages`: Individual HTML pages for the book.
  - `/images`: High-quality images and illustrations.
  - `/graphics`: Vector graphics and icons.
  - `/sources`: Research sources and documentation.
  - `/styles`: CSS stylesheets for EPUB/Web rendering.
  - `/metadata`: EPUB metadata and configuration.

## Author
Faisal Orakzai

## Goal
To create a premium, publication-quality digital book (EPUB 3) and a high-quality print-ready version that blends historical heritage with modern technology.
