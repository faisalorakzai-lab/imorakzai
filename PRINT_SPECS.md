# Print Specifications

This document outlines the requirements for the physical print version of **I’M ORAKZAI**.

## 1. Resolution
- All images must be at least **300 DPI** at their final print size.
- Current cover image (`book/images/cover.png`) should be replaced with a high-resolution TIFF or lossless PNG if a higher resolution version is available.

## 2. Color Space
- Digital/Ebook: **RGB**
- Physical Print: **CMYK** (for the final PDF export).

## 3. Layout and Bleed
- **Bleed**: 0.125 inches (3mm) on all sides for full-page images.
- **Margins**: Safe area for text should be at least 0.5 inches from the edge.
- **Gutter**: Appropriate spacing for binding (depends on final page count).

## 4. Typography
- Fonts must be embedded in the final PDF.
- Use vector-based graphics for icons and ornaments where possible.

## 5. Export Format
- Final print file should be a **PDF/X-1a** or **PDF/X-4** compliant document.
